# Changelog

## [1.0.0] — Unreleased
### Added
- Initial release.
- Three layouts: Vertical timeline, Compact list, Executive cards.
- Status normalisation (Open / In Progress / Closed / Blocked / Other) and severity normalisation (Low / Medium / High / Critical / Normal).
- Optional KPI summary row driven by Current / Previous / Variance / Variance % measures.
- Configurable date format, number format, currency symbol, decimal places.
- Full palette override per status and per severity.
- Accessibility: aria-labels, keyboard-reachable items, high-contrast support, dashed badge for unknown statuses.
